## Files

- `title-select-style-guide.pdf`: nine-page visual guide.
- `title-select-style-guide.md`: editable identity and product-language specification.
- `title-select-logo-color.png`: primary transparent logo, 1983 × 793 px.
- `title-select-icon-color.png`: matching transparent selector icon, 1254 × 1254 px.
- `title-select-logo.png`: retained single-color cobalt logo.
- `title-select-icon.png`: retained single-color cobalt icon; preferred at small sizes.
- `title-select-direction.png`: cover preview of the updated identity.
- `title-select-tokens.css`: reusable colors, typography, spacing and motion tokens.
- `generation-prompts.txt`: prompts and generation method for both asset treatments.

The selector emblem represents one chosen release within a preserved set. Cobalt outer bars and brackets surround a red selected bar and a yellow cursor; the wordmark stays cobalt. Arcade marquee hierarchy, console packaging structure and handheld menu economy inform one shared identity. MAME collections are explicitly within scope.

Pixel lettering is an occasional campaign accent. Main typography stays smooth and readable. The optional cobalt-to-violet gradient is documented for promotional use, but a gradient logo asset is not included.

Logo and icon were produced with the built-in image-generation tool and are raster PNGs with minor color variations. Vector masters and reversed artwork remain production refinements. The interface and campaign examples are illustrative. Font files are not bundled; the pixel READY specimen is original grid lettering in the PDF.
